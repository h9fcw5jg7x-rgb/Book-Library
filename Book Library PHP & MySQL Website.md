# Book Library PHP & MySQL Website
This is a simple book library web application built using PHP and MySQL.

## Features
✅ View all books on the homepage
✅ Search books by title or author
✅ Add a new book
✅ Edit existing book information
✅ Delete a book

## Project Files
- `db.php` — MySQL database connection
- `index.php` — Homepage, list all books + search
- `addbook.php` — Form to add new books
- `editbook.php` — Form to update book details
- `deletebook.php` — Delete a book from the database

## How to run
Upload all PHP files to mi‑Linux, create the books table in phpMyAdmin, then open `index.php` in your browser.
